# Rubrics

A **rubric** says how an evaluated attempt becomes points. You attach one to a problem on an
assignment, from that problem's settings.

Rubrics are yours rather than a course's. You can attach the same rubric to as many problems,
on as many assignments, in as many of your courses as you like, and keep using it from one term
to the next.

## What a rubric does today

There is one kind of rubric for now: **full points when the answer is correct, nothing
otherwise**. That is exactly how a problem with no rubric is graded, so attaching one does not
change any grade. The rubric screens, the setting on each problem and the record kept with each
attempt are all in place so that partial credit can be added later without changing how you
work.

## Manage your rubrics

Open a course, select **Problems**, then **Rubrics**. Administrators also have **Rubrics** in the
**Administration** menu.

- **New Rubric** creates one from a name and an optional description.
- **Rename** changes what it is called. How it grades stays the same.
- **Duplicate** copies it into your own library.
- **Delete** removes it. A rubric that is attached to any problem cannot be deleted; take it off
  those problems first. **Show where** lists the problems that use it.

TAs and co-instructors see the rubrics attached in courses they teach, marked with the owner's
name, and can attach those to other problems in the same course. Only the owner (or an
administrator) can rename or delete a rubric; anybody else duplicates it to get a copy of their
own.

## Attach a rubric to a problem

1. Open the assignment and select its **Problems** tab.
2. **Manage** the problem and open its settings.
3. Choose a rubric under **Rubric**, or **None**, and save.

The list offers your own rubrics and any rubric already used in this course.

## Changing a rubric does not re-mark work

Each attempt keeps a copy of the rubric it was graded under, in the same way it records the
answer file. Changing or detaching a rubric applies to attempts graded afterwards; to re-mark
earlier work, re-run those submissions from the assignment's **Submissions** tab.

## Copying courses and assignments

Duplicating or importing an assignment or a course keeps each problem's rubric, because the
rubric belongs to an instructor rather than to the course it was used in.
